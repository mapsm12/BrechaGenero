# BrechaGeneroV4

Dashboard interactivo sobre brecha de género, cuidados y liderazgo político en Perú, integrando métricas derivadas de ENAHO 2008–2024 y autoridades electas del JNE.

## Contenido

- Brechas socioeconómicas por departamento y año
- Penalidades de maternidad proxy
- Indicadores de representación y liderazgo político femenino
- Índice compuesto de entorno habilitante para liderazgo femenino
- Visualización territorial, tendencias, cruces y tablas comparativas

## Fuente de datos

- ENAHO 2008–2024 procesada a nivel analítico
- Autoridades electas del JNE
- Centroides departamentales para visualización territorial

## Nota

Este Space corre con Docker y carga los archivos desde la carpeta `data_dashboard/`.
